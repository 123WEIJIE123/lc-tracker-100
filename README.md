# 力扣热题100 · 三刷打卡器

本地单文件刷题打卡工具，**双击 `index.html` 即可使用**，无需安装任何依赖。

> 合并了 `lc-tracker`（高频20题）与 `lc-tracker-80`（剩余80题）两版，共 **100 题**，按力扣官方 Hot 100 顺序排列。

## 功能

- 📋 **每日打卡** — 按「2旧题 + 2新题 + 1薄弱」公式记录，同一天多次保存会**累积追加**（不覆盖），自动联动三刷进度
- 📊 **三刷追踪** — 100 题按 17 个分类、官方顺序组织，每道题记录 3 次刷题日期，点击题号直达力扣网页；采用卡片式布局，窄屏自动换行，**无需左右滚动**
- 📈 **进度统计** — 环形图、分类进度条、热力图、薄弱项分析
- 🔍 **筛选** — 按难度 / 分类筛选，快速定位目标题
- 🔁 **数据合并** — 首次打开自动导入 `lc20_tracker` / `lc80_tracker` 的历史数据；也可随时手动「合并20/80数据」
- 💾 **数据导出/导入** — JSON 格式备份（支持覆盖导入与合并导入）

## 使用方法

1. 下载 `index.html`
2. 双击用浏览器打开（首次打开会自动合并 20/80 两版的历史数据）
3. 数据自动保存在浏览器本地存储（localStorage，key `lc100_tracker`）
4. 建议每周导出一次 JSON 备份
